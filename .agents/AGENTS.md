# Project Rules

## Combo Selections Rule (QR Ordering)
- If a combo dish has a price of `$0.00` (free base price), the customer **must** make their selections (the "Skip Selections" option is hidden).
- If the combo dish has a base price greater than `$0.00`, the "Add Base Combo Directly (Skip Selections)" option must be displayed to allow customers to skip combo choices.
